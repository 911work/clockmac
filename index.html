Откуда рекрутёры

Tier-лист стран-источников: объём потока × Шенген-одобрение × платёжеспособность мигрантов

Методология: Публичной статистики по VET-визам нет. Tier-лист = корреляция Шенген-отказа 2024 (DG HOME), education-ВНЖ (Eurostat) и объёма/платёжеспособности. Студенческие визы (тип D) одобряются лучше туристических — есть зачисление и гарантии.

Ограничения: Шенген-отказ ≠ отказ по студенческой визе. Нет разбивки education-ВНЖ по типу программы. Для стран без точных данных 2024 (~) — оценки по 2023 + региональным трендам. DG HOME публикует полный Excel, но в пресс-релизах — только выборочные страны. ЮАР, Ботсвана, Намибия — исключения с низким отказом в Африке.
